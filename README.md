# LyveFlow Releases

Installers and update files for the LyveFlow desktop app for Windows. LyveFlow
updates itself from this repository, so you only install it once.

**Download the latest installer:** https://github.com/Radlincs/LyveFlow-Releases/releases/latest

Windows may say it protected your PC, because the installer is not signed yet.
Choose More info, then Run anyway.

The source code is private. This repository only makes the installers public.
